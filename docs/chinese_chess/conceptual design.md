# 《中国象棋 3D》概念设计

> 交付物：`games/chinese_chess.html`（单文件，零外部依赖，双击即玩）
> 本文件：`docs/chinese_chess/conceptual design.md`

## 一、项目概述

《中国象棋 3D》是 OneTab Tabletop 桌游集中的第二款成品，也是系列的**首个真 3D 作品**：透视相机、实时光照、PCF 软阴影、PBR 材质与车削立体棋子，全部在一个 HTML 文件内离线运行。

- **定位**：1~2 人同设备的中国象棋完整实现，内置四档人机 AI。
- **技术基调**：沿用项目「一游戏一文件、零外部依赖」标准（Three.js r149 UMD 内联、Canvas 运行时纹理、WebAudio 合成音效），相对《荣光宝石商》的正交 2.5D 方案**有意升级为真 3D**。
- **体验目标**：木质暖金视觉、触屏优先、移动端竖屏可顺畅对弈；打开即见有光影与质感的大棋盘。

| 项目 | 参数 |
|---|---|
| 玩家人数 | 1（人机）/ 2（同机轮流） |
| 单局时长 | 5~30 分钟 |
| 界面语言 | 简体中文 |
| 文件体积 | ≈ 710 KB（three.js 内联约 608 KB） |

## 二、玩法规则

### 2.1 棋盘与棋子

- 棋盘 **9 纵线 × 10 横线**，中为河界（楚河 / 汉界），两端各有九宫（含对角斜线）。
- 双方各 16 子：将(帅)×1、士(仕)×2、象(相)×2、马×2、车×2、炮×2、卒(兵)×5。
- 红方先行；红方在下（近端），黑方在上（远端）。

### 2.2 走法

| 棋子 | 规则 |
|---|---|
| 车 | 直线任意步，路径不得有子 |
| 马 | 走日字；前进方向相邻点有子（蹩马腿）则不可走 |
| 象 / 相 | 走田字；田字中心有子（塞象眼）不可走；不得过河 |
| 士 / 仕 | 九宫内斜走一步 |
| 将 / 帅 | 九宫内直走一步；将帅不得照面（同纵线中间无子） |
| 炮 | 移动同车；吃子必须且仅隔一子（炮架） |
| 卒 / 兵 | 未过河只向前一步；过河后可左右横走；永不后退 |

### 2.3 合法性

- 走子后己方将帅不得被将军（送将非法，含因照面产生的暴露将军）。
- 非法落点会给出具体原因提示（「马腿被蹩」「不能送将」「将帅不能照面」等）。

### 2.4 终局与和棋

- **将死**（被将军且无着可解）判负；**困毙**（未被将军但无着可走）同样判负（中国象棋规则）。
- **认输**立即判负。
- **三次重复局面**判和；若重复循环中某一方每一手都在将军（**长将**），改判长将方负。
- **自然限着**：连续 60 回合（120 步）无吃子判和。
- 结算展示：胜方、终局原因、着数、回合数、耗时。

### 2.5 记谱

- 标准中文纵线记谱：红方纵线从右到左记一~九，黑方从左到右记 1~9。
- 动作词 进 / 退 / 平；同纵线同种子力以 前 / 中 / 后 区分（如 `前车进三`）。
- 对局记谱面板按回合对列双方着法；历史记录支持逐步回放。

### 2.6 对局模式差异

| 模式 | 视角 | 操作 |
|---|---|---|
| 单人（人机） | 固定正对玩家（执红正立 / 执黑转 180°） | 玩家走子后 AI 自动应答 |
| 双人（同机） | 默认俯视全景；可开「视角跟随走子方」 | 黑方棋子文字旋转 180° 便于对面玩家正读 |

## 三、游戏流程

```
加载页 → 首页（3D 棋盘环绕背景）
  ├─ 单人对战 → 人机配置（难度四档 + 执红/执黑） → 对局
  ├─ 双人对战 → 对局
  ├─ 继续对局（有存档时显示） → 对局
  ├─ 玩法说明（弹窗）
  └─ 对局记录（弹窗） → 点击记录 → 回放模式（前进 / 后退 / 重置 / 退出）

对局中：顶部信息条（行棋方 / 将军提示 / 回合 / 计时）
        底部操作栏（悔棋 / 提示 / 记谱 / 认输 / 重开 / 暂停）
终局 → 结算屏（胜方高亮 / 原因 / 数据） → 再来一局 / 换边再战 / 返回首页
```

- 每次走子后自动写入 `cc_save_v1`；关闭页面重开可续局；坏档静默丢弃回首页。
- 每局结束写入 `cc_records_v1`（最新在前，上限 50 条，0 着无效局不记）。

## 四、道具列表

### 4.1 棋盘

- 棋盘面：Canvas 绘制木纹 + 格线 + 九宫斜线 + 炮/兵位十字标记 + 楚河汉界四字，`MeshStandardMaterial`（roughness 0.55）。
- 深色木质外框 + 四角装饰柱；棋盘面接收棋子投影。

### 4.2 棋子

- `LatheGeometry` 车削圆饼鼓形（顶平、侧微弧、底收边），32 枚共用同一剖面。
- 顶面贴图按「阵营 + 字」缓存：红方 `#b3241c` 底 + 白描边 + 阴刻字；黑方 `#1d1d1d` 底同款。
- 直径 0.85 格、厚 0.24 格；将/帅使用独立材质实例以支持将军红色脉冲。

### 4.3 界面元素

| 元素 | 说明 |
|---|---|
| 选中光晕 | 棋子下方呼吸光环（opacity 0.75±0.25） |
| 落点标记 | 合法空位金绿圆盘 / 吃子位红色圆盘 |
| 上一步标记 | 起止两格方框（蓝灰 = 起，金 = 止） |
| 将军脉冲 | 被将军方将/帅红色发光脉冲 + 信息条「将军！」 |
| 被吃子托盘 | 棋盘左右两侧，陈列双方战利品 |
| 提示标记 | 绿色方框标出推荐着法起止格（约 2.6s 自动消失） |
| 3D 光标 | 手柄 / 键盘导航用的金色方框光标 |

## 五、技术架构

### 5.1 文件结构（单文件内分块）

1. `<style>` —— 加载页 / 信息条 / 操作栏 / 弹窗 / 记谱面板 / 首页菜单 / 结算
2. `<script>` —— 内联 three.js r149 UMD 压缩源码（复用自《荣光宝石商》）
3. `<script>` 数据层 —— 棋盘常量、棋子定义、子力价值、位置价值表 PST、`AI_LEVELS`
4. `<script>` 规则引擎 —— 走法生成 / 合法性 / 将军 / 终局（含长将循环节分析）/ 记谱 / 悔棋，挂 `window.CC_RULES`
5. `<script>` AI 层 —— `negamax + alphaBeta + quiescence`、置换表、杀手着法、历史启发、迭代加深；`decideAsync` 逐层 `setTimeout(0)` 让帧（单片 ≤110ms），挂 `window.CC_AI`
6. `<script>` UI 层 —— `makeTex` / `text` / `mkTextMesh` / `addClickable` / `hitTest` / `setGlow` / `Tween` / `Busy` / WebAudio 音效 / 确认弹窗
7. `<script>` 场景层 —— 渲染器 / 光照 / 程序化纹理 / 棋盘棋子建模 / `fitCamera` / `Home` / `GameScreen` / 弹窗群 / `EndScreen` / 存档与记录
8. `<script>` PadNav —— 键盘方向键 + 手柄轮询，3D 棋盘光标，与触摸共用 `dispatchTap` 入口
9. `<script>` 主入口 —— `initApp` / `resize` / `rebuildScreen` / `dispatchTap` / `playSfx` / `animate`

### 5.2 技术要点

- **真 3D**：`PerspectiveCamera` + `HemisphereLight` / `DirectionalLight`（PCFSoft 阴影，低端 1024 / 桌面 2048）+ `MeshStandardMaterial`；`fitCamera()` 按视口宽高比自动调 FOV 与距离，竖屏放大 FOV 让棋盘竖放占满。
- **规则内核纯逻辑**：数据层 + 规则引擎 + AI 不依赖 DOM / Three.js，Node 可直接提取单测（`tests/chinese_chess_rules.test.js`，17 项断言全绿）。
- **AI 不卡帧**：搜索内每 512 节点检查时限，迭代加深每层之间让帧，任何单次同步阻塞 ≤110ms；思考延时 260+lv×220+(1~3s 随机) 节奏与项目惯例一致。
- **纹理与资源管理**：`TEX` Map 缓存（key 带尺寸）、共享棋子几何与材质（`userData.shared` 跳过逐件 dispose）、场景重建 `TEX.clear()` + `disposeMats()`。
- **持久化**：`cc_save_v1`（当前局）/ `cc_records_v1`（历史 50）/ `cc_settings_v1`（静音、视角跟随）；读档逐字段校验，坏档静默丢弃。
- **输入屏蔽**：`Busy` 计数 + `AI.running`，落子 / 吃子 / 思考 / 结算期间屏蔽拾取分发。

### 5.3 构建与测试

```bash
# 单文件校验（语法 + 外链负面清单 + 体积）
node dev/check_single_file.js games/chinese_chess.html

# 规则内核单测
node --test tests/chinese_chess_rules.test.js

# 端到端冒烟（需本机 Chrome + playwright-core）
node dev/smoke_chinese_chess.js
```

无构建步骤；浏览器直接打开 `games/chinese_chess.html` 即玩。
