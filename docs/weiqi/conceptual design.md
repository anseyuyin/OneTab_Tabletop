# 《围棋 3D》概念设计文档

## 一、项目概述

《围棋 3D》是 OneTab Tabletop「一游戏一文件」系列的第三款成品：在单文件 HTML 中实现完整可玩、可离线运行的 3D 围棋。支持 1~2 人同设备游玩（人机等宽四档难度 / 双人轮流），9 / 13 / 19 路三种盘面，让子与贴目配置，中国规则数子法结算。

- **交付形态**：`games/weiqi.html` 单文件，双击即玩，断网可用，零外部依赖。
- **美术基调**：中式竹林庭院 —— 青石石桌承托薄木棋盘、蛤贝白子与那智黑石、木棋笥、石板地面、实例化竹林与石灯笼点缀；配色保留项目金色系基因（米白纸色 `#f2e6cf` / 墨黑 `#1a1614` / 木金 `#c8a06a` / 朱红 `#b23a2e`）。对局相机为正俯视角（俯角约 83°），可小角度水平旋转与缩放。
- **AI 定位（如实标注）**：陪练级。9 路中坚档可稳定击败初学者；13 路娱乐陪练；19 路以体验为主，局部战斗有反应、全局战略较弱。
- **美术资产路径**：采用方案 A（全程序化几何 + Canvas 程序化纹理），未使用 Blender 内联资产；无 `docs/weiqi/res/` 运行时资产。

## 二、玩法规则

### 2.1 棋盘与棋子

- 9 / 13 / 19 路（默认 19 路），N 路 = N×N 交叉点。
- 星位：19 路 9 个（含天元），13 / 9 路 5 个（四角 + 天元）。
- 坐标记法：横轴 A~T（跳过 I），纵轴 1~19 自下而上，如 `Q16`、`D4`。
- 黑先白后；让子 2~9 子预置于标准让子点，白方先行，让子时贴目默认 0.5。

### 2.2 气与提子

- 同色棋子上下左右（不含对角）相连成块，块紧邻的空点为「气」，棋盘边界外不算气。
- 落子后先提对方气为 0 的整块棋；被提子计入己方提子数。
- 禁入点：落子后己方块无气且未提子 → 禁着（自杀）；提子后自杀为合法手。

### 2.3 打劫与禁着

- 主对局采用全局同形禁着（superko）：Zobrist 哈希维护局面历史，落子后局面与历史任一局面相同即非法（打劫不能立即回提，须先走劫材）。
- AI 模拟（playout）内部使用简单劫（禁止立即回提单子劫）以省性能。
- 停一手（pass）允许；双方连续停一手进入数子阶段。

### 2.4 终局与数子（中国规则 · 数子法）

1. 双方连续停一手，或任一方点击「数子」并经双方同意后，进入数子阶段。
2. 系统自动提议死子（启发式：棋块邻接的空点区域全部被对方控制则判死），棋盘上以朱红 × 标记；点击棋子可切换死活，目数明细实时刷新。
3. 双人模式需黑 / 白双方各确认一次；人机模式玩家确认即可（AI 以自身评估核对，差距过大则拒绝并提示继续对弈）。「自动判定」恢复系统提议；「继续对弈」取消数子回到对局。
4. 结算：死子移出后，某方子数 = 盘上子数 + 围住的空点；空点区域只与一方相邻归该方，同时邻接双方（公气 / 双活）为中立不计；黑总子数 > 半数 + 贴目即胜，展示胜出差值并标注「中国规则 · 数子」。
5. 其他终局：认输立即判负；关闭 superko 时同一局面三次重复判无胜负（本作默认开启 superko）。

### 2.5 让子与贴目

- 贴目：19 路默认 7.5，13 / 9 路默认 6.5；可选 0.5 / 5.5 / 6.5 / 7.5。
- 让子 0~9 子（标准让子点组合）；让子与贴目同时作用于数子结算与 AI 评估。

### 2.6 模式差异

| 模式 | 说明 |
|---|---|
| 单人（人机） | 玩家执黑或执白，另一方由 AI 控制；执白时棋盘整体旋转 180° 正对玩家 |
| 双人（同机） | 黑方坐下方、白方坐上方（上方 UI 文字倒置）；对局中视角固定不随回合旋转，双方共用同一正俯视画面 |

## 三、游戏流程

1. **加载页**：黑白子交替浮动 + 标题淡入 + 木金进度条，构建完成后淡出。
2. **首页**：3D 背景（棋墩静置 + 缓慢环绕 + 隐约落子）+ 菜单：单人对弈 / 双人对弈 / 继续对局（有存档才显示）/ 玩法说明 / 对局记录 / 设置。
3. **对局设置**：盘面尺寸、AI 难度（四档色标徽标）、执子、让子、贴目。
4. **对局**：点击交叉点落子（触屏可开二次确认）→ 落子动画 + 音效 → 提子动画 → 更新信息；顶部信息条（提子数 / 手数 / 当前行棋方 / 贴目让子 / AI 思考提示），底部操作栏（悔棋 / 停一手 / 形势判断 / 手数 / 数子 / 认输 / 棋谱 / 菜单）。
5. **数子**：死子标记 → 双方确认 → 结算。
6. **结算**：胜方高亮 + 目数明细 + 终局原因 + 手数 / 提子 / 耗时；再来一局 / 换边再战 / 返回首页。
7. **回放**：棋谱面板点击任意手跳转，或记录弹窗中复盘历史对局（前进 / 后退 / 开局 / 末手 / 退出）。

## 五、技术架构

### 5.1 文件结构（单文件内分块）

1. `<style>`：加载页 / 信息条 / 操作栏 / 弹窗 / 棋谱面板 / 首页 / 数子面板 / 结算 / 竖屏适配
2. `<script>`：内联 three.js r149 UMD 压缩源码（与 `chinese_chess.html` 同源整段复制）
3. `<script>` 数据层：盘面常量 / 星位与让子表 / 贴目 / `AI_LEVELS` / 开局书
4. `<script>` 规则引擎（`window.WQ_RULES`，纯逻辑可 Node 单测）
5. `<script>` AI 层（`window.WQ_AI`：候选点 / 真眼 / 启发 / MCTS / 分片调度）
6. `<script>` UI 层：纹理工厂 / 拾取 / 缓动 / Busy / WebAudio 音效 / 通用弹窗
7. `<script>` 场景层（一）：渲染器 / 光照 / 程序化纹理 / 建模 / 相机手势
8. `<script>` 场景层（二、三）：全局状态 / 存档记录 / 首页 / 对局 / 数子 / 结算 / 帮助 / 记录
9. `<script>` PadNav：手柄键盘导航（3D 交叉点光标，与触摸共用 `dispatchTap`）
10. `<script>` 主入口：`initApp` / `resize` / `dispatchTap` / `animate`

### 5.2 技术要点

- **规则内核**：`Int8Array` 局面 + Zobrist 哈希（superko）；气 / 连通块 / 提子 / 禁着 / 数子（一次洪水填充 O(N²)）纯函数实现，Node `--test` 逐条断言（`tests/weiqi_rules.test.js`，17 项）。
- **棋子渲染**：黑白各一个 `InstancedMesh`（共享 ≤ 320 三角形的 Lathe 几何与材质），落子用独立 Mesh 播动画后写入实例，提子用「末尾交换 + count--」回收；实例网格投影阴影，同屏 mesh 数（不含实例）< 80。
- **拾取**：数子阶段 `Raycaster` 命中 InstancedMesh（`instanceId`）；落子走棋盘平面求交 + `gridFromWorld`（±0.45 格容差）；坐标换算集中于 `worldFromGrid` / `gridFromWorld` / `intersectionIndex`。
- **AI**：候选点启发排序（吃子 / 打吃 / 逃气 / 连接 / 大场）+ 真眼检测（任何阶段不填己眼，无有效着法自动停一手）；3、4 档为轻量 MCTS（UCB1 C=1.0 + 启发 playout + 简单劫），每 ≤ 80 ms 分片让帧，预算 500 / 1300 ms，低胜率认输（样本数门槛防误判）；开局书 + 微随机。
- **持久化**：`wq_save_v1`（当前对局，逐字段校验 + 历史重放自洽，坏档静默丢弃）/ `wq_records_v1`（50 条上限）/ `wq_settings_v1`。
- **性能**：DPR ≤ 2、`TEX` 纹理缓存（场景重建 `TEX.clear()`）、共享几何材质跳过 `disposeGroup`、resize 防抖 200 ms（旋转 250 ms）。
- **画质三档**（设置内一键切换，首次运行按设备能力自选：桌面 → 高，移动端多核 → 中，其余 → 低）：

  | 档位 | 渲染倍率 | 阴影 | 场景细节 |
  |---|---|---|---|
  | 低 | 1.25× | 1024 · 硬阴影（PCF） | 关闭远景竹丛 / 接地柔影 / 石灯笼点光，补光减弱，暗角最轻 |
  | 中 | 1.6× | 2048（移动端 1024）· 软阴影（PCFSoft） | 完整场景与补光，中等暗角 |
  | 高 | 2× | 2048 · 软阴影 | 完整场景，最强暗角与补光 |

  切换渲染倍率时会重建共享棋子贴图与盘面贴图（`stoneAssets(true)` + `TEX.clear()` + 场景重建），保证清晰度与显存开销同步；对局中切换不会丢失棋子、提子数与最后一手标记。

### 5.3 构建与测试

```bash
# 语法 / 外链负面清单 / 体积校验
node dev/check_single_file.js games/weiqi.html
# 规则内核单测（17 项断言）
node --test tests/weiqi_rules.test.js
# AI 校验（MCTS 耗时 / 合法性 / 自对弈自然终局）
node dev/ai_weiqi_check.js
# 端到端冒烟（playwright-core + 本机 Chrome）
node dev/smoke_weiqi.js
# 画质档位校验（低 / 中 / 高参数与对局中切换不丢子）
node dev/quality_weiqi.js
```

当前指标：文件体积约 736 KB（上限 900 KB）；单测 17/17 通过；冒烟全流程零报错；MCTS 单着 9 路 ≤ 0.5 s（困难）/ ≤ 1.3 s（大师）。
