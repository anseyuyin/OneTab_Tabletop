② Base64 JSON → 图片

JSON 格式说明

[
  {
    "图名1": "data:image/png;base64,iVBOR...",
    "图名2": "data:image/jpeg;base64,/9j/..."
  },
  {
    "图名3": "纯 base64 字符串（可省略前缀）"
  }
]

数组的每个元素是一组图片：键为图片名，值为 Base64 字符串（带或不带 data: 前缀均可，纯字符串会自动识别图片格式）。 多次拖拽 / 多个对象即生成多组。
